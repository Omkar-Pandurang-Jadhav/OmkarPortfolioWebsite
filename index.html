GrowKaro

An AI-powered competitor intelligence platform that turns raw market data into actionable strategic insights — in real time.

GitHub Software Copyright
Overview

GrowKaro is a full-stack AI platform built to solve a real problem for startups and small businesses: understanding what competitors are doing without spending hours on manual research. The system automatically collects data from competitor websites and social channels, processes it through NLP pipelines, and surfaces the most relevant insights through a conversational AI interface.

The project received Software Copyright recognition from the Government of India for its novel AI-driven competitive analysis methodology — a formal validation of the technical approach.

Key Features
  • Real-Time Web Scraping Pipeline Automated scrapers continuously monitor competitor websites, product pages, and pricing updates. Data is normalized and stored for downstream analysis.
  • NLP-Based Sentiment Analysis Customer reviews, social mentions, and market commentary are processed through sentiment models to quantify brand perception and track shifts over time.
  • Conversational AI Intelligence Layer A natural language interface lets business users ask plain-English questions and receive structured, contextual answers backed by live competitor data.
  • Microservices Architecture with Docker Each component — scraper, NLP engine, AI chat, database — runs in isolated Docker containers enabling independent scaling and fault-tolerant deployments.
  • Government of India Software Copyright The unique methodology for AI-driven competitive intelligence was formally recognized and awarded a software copyright — establishing intellectual property of the approach.
Architecture
Data Layer
Web Scraping Engine — Scheduled crawlers fetch structured and unstructured data from competitor sources, handling rate-limiting and data deduplication.
Processing
NLP Pipeline — Raw text is cleaned, tokenized, and passed through sentiment classification and entity extraction to produce structured insight records.
Storage
Database Layer — Processed insights persisted in a relational database, indexed for fast retrieval and trend computation.
AI Interface
Conversational Layer — A RAG-style interface retrieves relevant insight chunks and generates coherent, accurate responses to user queries about market conditions.
Deployment
Docker Compose — All services orchestrated via Docker, enabling reproducible deployment with minimal configuration.

FloatChat

A domain-specific scientific conversational assistant powered by retrieval-augmented generation — delivering accurate, grounded answers to complex queries.

GitHub
Overview

FloatChat is a specialized conversational AI built to handle complex scientific and technical questions with precision. Unlike general-purpose chatbots that may hallucinate or give vague answers, FloatChat grounds every response in retrieved factual sources through a Retrieval-Augmented Generation (RAG) architecture.

The system was built with a focus on response accuracy, low latency, and the ability to reason over structured knowledge — making it suitable for research assistance, technical Q&A, and educational support in scientific domains.

Key Features
  • Retrieval-Augmented Generation (RAG) Before generating any answer, FloatChat retrieves the most semantically relevant passages from a curated knowledge base — ensuring factually grounded responses.
  • Scientific Domain Specialization Fine-tuned and prompted to handle complex scientific terminology, multi-step reasoning, and technical concepts across physics, chemistry, biology, and engineering.
  • Low-Latency Response Optimization Prompt engineering, chunk-size tuning, and efficient embedding retrieval combine to keep response times fast even for complex multi-turn conversations.
  • Structured Reasoning The chatbot thinks step-by-step through complex queries, breaking down multi-part questions before composing a final answer — improving coherence and accuracy.
  • Multi-Turn Conversation Handling FloatChat maintains conversational context across turns, allowing users to ask follow-up questions naturally without re-stating context each time.
How It Works
User Query
Input Processing — The user's question is pre-processed. Entity recognition and classification determine the retrieval strategy.
Retrieval
Semantic Search — Query converted to a dense embedding vector; top-k most relevant chunks retrieved from the vector knowledge base.
Augmentation
Context Assembly — Retrieved chunks assembled into a structured prompt alongside the original question and conversation history.
Generation
LLM Response — The augmented prompt is sent to the language model, which generates a grounded response constrained by the provided context.
Output
Formatted Answer — Response returned with optional source attribution for full transparency about what knowledge was used.

CrickHero

A cricket analytics dashboard that transforms raw match data into rich visual insights — from player form trends to match outcome predictions.

GitHub
Overview

CrickHero is a data analytics platform for cricket enthusiasts, analysts, and fantasy sports players. It processes large historical match datasets to produce meaningful visualizations and predictive insights not typically available in mainstream cricket apps.

The project demonstrates end-to-end data engineering — from ingesting raw CSV data through normalization, statistical modeling, and interactive visualization — all optimized for fast query responses over large datasets.

Key Features
  • Interactive Performance Dashboard Batting averages, strike rates, bowling economy, and wicket-taking patterns visualized across Test, ODI, and T20 formats with filterable, interactive charts.
  • Form Trend Analysis Statistical rolling averages and momentum indicators surface whether a player is in peak form, declining, or recovering — directly informing team selection and fantasy picks.
  • Match Outcome Prediction Statistical models trained on historical head-to-head records, venue conditions, and team composition data generate match outcome probabilities with meaningful accuracy.
  • Normalized Historical Dataset Raw match data from multiple formats and eras cleaned, deduplicated, and normalized into a consistent schema — enabling cross-format comparisons and longitudinal analysis.
  • Optimized Query Performance Proper indexing, aggregated materialized views, and query caching ensure fast responses even when analyzing decades of match data across thousands of players.
Data Pipeline
Ingestion
Raw Data Collection — Historical match data sourced from public cricket datasets in CSV format, covering multiple formats and years of professional play.
Cleaning
Data Normalization — Inconsistent spellings, missing values, format inconsistencies, and duplicates resolved through automated cleaning scripts.
Modeling
Statistical Analysis — Rolling averages, batting/bowling ratings, and outcome prediction models computed and stored as derived tables for fast lookup.
Storage
Relational Database — Normalized schema with foreign keys linking players, teams, matches, and innings for efficient multi-dimensional queries.
Visualization
Interactive Dashboard — Charts and tables rendered dynamically based on user-selected filters: player, format, date range, and venue.
